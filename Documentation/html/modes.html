Operational Modes

This station has two main operational modes.

1. Manual Mode All instruments and actuators are controlled through manual button presses on the Manual Operation page. Only Administrator users have access to this page.

2. Auto (Production) Mode Can only be entered when the station is homed and all faults cleared. This mode allows the station to act automatically based on sensor and upstream/downstream inputs.

The Main Interface features some buttons with multi-state indicators. They are shown as grey buttons with an outer indicator boarder. The below table goes over the general meaning behind these indicators.

The light towers on the station also reflect the indicator for the Auto button.
