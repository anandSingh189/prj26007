This station has two main operational modes.

{\bfseries{1. Manual Mode}} All instruments and actuators are controlled through manual button presses on the \mbox{\hyperlink{gui_gui_manual}{Manual Operation}} page. Only \mbox{\hyperlink{gui_gui_main_user}{Administrator}} users have access to this page.

{\bfseries{2. Auto (Production) Mode}} Can only be entered when the station is \mbox{\hyperlink{gui_gui_main_home}{homed}} and all \mbox{\hyperlink{faults}{faults}} cleared. This mode allows the station to act automatically based on sensor and upstream/downstream inputs.

The \mbox{\hyperlink{gui_gui_main}{Main Interface}} features some buttons with multi-\/state indicators. They are shown as grey buttons with an outer indicator boarder. The below table goes over the general meaning behind these indicators.

The light towers on the station also reflect the indicator for the {\bfseries{Auto}} button.
