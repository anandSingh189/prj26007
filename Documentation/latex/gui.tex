\mbox{\hyperlink{gui_gui_main_top}{To Top}}\hypertarget{gui_gui_main_home}{}\doxysubsection{2. Station Homing}\label{gui_gui_main_home}
\index{Station Homing@{Station Homing}} \index{RFID Fixture Check@{RFID Fixture Check}}

The station needs to be in the homed state prior to entering Auto Mode. The homing sequence is started by pressing the {\bfseries{Home}} button while in Manual Mode. The homing is considered complete when all indicators are green. The homing sequence has a hard time out of 2 minutes.

{\bfseries{RFID Fixture Check}} Once both nest cylinders are in the home position, each nest fixture is at its RFID head. The homing sequence then scans the fixture RFID tag of Nest 1 followed by Nest 2 and compares each to the expected fixture value for the current module type (Short or Long) received from the previous station.
\begin{DoxyItemize}
\item If the tag matches, homing continues to the next step.
\item If the tag does not match, homing stops and a \mbox{\hyperlink{faults}{RFID mismatch fault}} is raised for that nest. Install the correct fixture, or write the correct value to the tag through the \mbox{\hyperlink{gui_gui_manual_rfid}{RFID Scanner}} controls, then reset the fault and re-\/run homing.
\end{DoxyItemize}

The RFID fixture check only runs as part of the homing sequence. The fixture check is cleared, and the station must be homed again before entering Auto Mode, when\+:
\begin{DoxyItemize}
\item The E-\/\+Stop is pressed
\item The module type received from the previous station changes
\end{DoxyItemize}

When changing over to a different module type, make sure the new module type has been received from the previous station before pressing {\bfseries{Home}}.
